
# 🐾 Pawtopia – Care Together. Play Together.

### A Family-Friendly Virtual Pet Care Game for Apple TV

Pawtopia is an interactive virtual pet care game developed for Apple TV using SwiftUI and tvOS. It transforms the television into a shared, family-friendly experience where players adopt virtual pets, complete care activities, earn rewards, and learn responsible pet ownership through playful interactions.

## 🎯 Project Overview

Pawtopia was developed as **Part B of the SE4041 – Mobile Application Design and Development Assignment 02**.

The project explores how Apple TV can provide an engaging gaming experience using the Siri Remote, focus-based navigation, and a large-screen interface.

**Tagline:** Care Together. Play Together.

**Platform:** Apple tvOS  
**Development Environment:** Xcode  
**Programming Language:** Swift  
**Framework:** SwiftUI  
**Testing Device:** Apple TV 4K (3rd generation) Simulator

## ✨ Key Features

### 🐶 Virtual Pet Adoption
- Choose from six adorable puppies and kittens.
- Give your adopted pet a personalized name.
- Start a new pet care adventure.

### 🍎 Feeding Mini-Game
- Identify safe and unsafe foods.
- Collect three suitable food portions.
- Feed the pet and improve its fullness.

### 🎾 Playing Mini-Game
- Participate in an interactive ball-catching activity.
- Navigate between positions using the Apple TV remote.
- Complete three successful catches.

### 🛁 Cleaning Mini-Game
- Follow a three-step bathing routine.
- Apply shampoo, rinse, and towel-dry the pet.
- Improve the pet's cleanliness.

### 🌙 Resting Mini-Game
- Prepare a comfortable sleeping area.
- Turn off the lights and play a visual lullaby activity.
- Restore the pet's energy.

### ❤️ Dynamic Pet Emotions
- Pet emotions respond to care status.
- Players can observe changes in the pet's well-being.

### 👨‍👩‍👧‍👦 Family Co-op Mode
- Supports solo play and family gameplay with 2–4 players.
- Players take turns caring for their shared virtual pet.
- Turn-based prompts encourage collaboration.

### ⭐ Rewards and Daily Missions
- Earn stars by completing pet care activities.
- Complete daily care missions.
- Track player progress and rewards.

### 🧠 Pet Care Quiz
- Answer pet care questions.
- Earn rewards for correct answers.
- Reinforce responsible pet care knowledge.

### 💾 Persistent Progress
- Save adopted pet details and care status.
- Continue previous gameplay sessions.
- Implemented using AppStorage.

## 🚀 How to Run

1. Clone or download this repository.
2. Open `Pawtopia.xcodeproj` using Xcode on macOS.
3. Select **Apple TV 4K (3rd generation) Simulator**.
4. Build and run the application.
5. Navigate using the Apple TV remote controls or simulator-supported keyboard controls.

## 🎮 How to Play

1. Launch Pawtopia and select **Start New Adventure**.
2. Choose a puppy or kitten.
3. Enter a name for your pet.
4. Select Solo or Family Mode.
5. Feed, Play, Clean, and Rest to maintain pet well-being.
6. Complete daily missions and quizzes to earn stars.
7. Continue caring for your pet across gameplay sessions.

## 💡 Innovation and Value Proposition

Pawtopia transforms everyday pet care into a cooperative living-room gaming experience.

Unlike traditional single-player mobile pet games, Pawtopia focuses on shared television interactions, turn-based family participation, simple remote-controlled mini-games, and positive pet care learning.
